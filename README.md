# causal-inference-project
Final project for DATA:4600 Causal Inference for Data Science

## Setup

Python 3.14.x

From the repository folder: 

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Verify:

```powershell
.\.venv\Scripts\python.exe --version
```
